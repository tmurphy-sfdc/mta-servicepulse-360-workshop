# MTA ServicePulse 360 Workshop

Two-day Salesforce workshop for the Metropolitan Transportation Authority (MTA) covering standard-first architecture, a deliberate custom object, platform capabilities (Validation, Flow, Prompt Builder, Approval, Reports), and Agentforce.

- **Dates:** October 19-20, 2026
- **Location:** MTA Headquarters, NYC
- **Live site:** published via GitHub Pages (see repo Settings > Pages for the URL)

## Repo contents

- `workshop-site/` — one-stop HTML landing page for participants (agenda, prerequisites, lab previews, instructor team, resources, Day 2 verify exercise). Hosted via GitHub Pages.
- `lab-manual/` — Participant guides and Instructor Notes for Labs 1 through 7, plus Lab 1.5 (Load MTA Sample Data), the Executive Scenario Simulation, John's Canary Brief, and the LAB-MANIFEST tracking revisions.
